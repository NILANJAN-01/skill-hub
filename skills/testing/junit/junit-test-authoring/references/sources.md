## Version facts used by the scripts

- JUnit 6: Java 17+ at runtime (older bytecode can still be tested), Kotlin 2.2+, Maven Surefire/Failsafe 3.0.0+ (the guide's examples use 3.5.5).
- Gradle: `useJUnitPlatform()` is required; declare `testRuntimeOnly("org.junit.platform:junit-platform-launcher")` (the guide recommends it; Gradle 9 requires it).
- Removed in 6.0: `junit-platform-runner` (`@RunWith(JUnitPlatform.class)`), `junit-platform-jfr`, `junit-platform-suite-commons`, `MethodOrderer.Alphanumeric`, `@UseTechnicalNames`, `@CsvFileSource(lineSeparator)`, `junit.jupiter.tempdir.scope`, `junit.jupiter.params.arguments.conversion.locale.format`, several Platform APIs. Deprecated: Vintage engine, `junit-jupiter-migrationsupport`, `JRE.JAVA_8`..`JAVA_16`, `getOrComputeIfAbsent`.
- New in 6.1: `@DefaultLocale`, `@DefaultTimeZone`, `@SetSystemProperty` / `@ClearSystemProperty` / `@RestoreSystemProperties` (`org.junit.jupiter.api.util`), `@TempDir(deletionStrategy)`, `org.junit.jupiter.api.Constants`, `worker_thread_pool` executor, Kotlin `assertThrowsExactly<T>`; `JRE.OTHER` and `org.junit.jupiter.engine.Constants` deprecated.

## Verified while building these skills

- Every Java example in `jupiter-api.md`, `parameterized.md` and `extensions-and-parallel.md`, and the Java test generated by `junit_scaffold.py`, was compiled with `javac -Xlint:deprecation` against `junit-jupiter-api`, `junit-jupiter-params`, `junit-platform-commons` and `junit-platform-suite-api` 6.1.3 (no errors, no deprecation warnings). Configuration keys were read from `org.junit.jupiter.api.Constants` in the 6.1.3 jar.
- Kotlin examples and generated Kotlin tests were not compiled.
- The report fixtures of `junit-run-reports` were written by hand from the documented formats (Surefire report XSD, Open Test Reporting 0.2.0 schemas), not produced by a real run.
