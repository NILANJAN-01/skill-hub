# Setting up Gradle for an Android project

Source: [sources.md](sources.md).

## 1. JDK

- AGP 8.x and 9.x need JDK 17 or newer (AGP 9.5 default: 17).
- Command line uses `JAVA_HOME` (or `java` on PATH). Check: `java -version` and `./gradlew --version` (shows the JVM Gradle uses).
- Android Studio uses its own **Gradle JDK** (Settings > Build, Execution, Deployment > Build Tools > Gradle). Make it the same JDK, or builds differ between IDE and terminal.
- To pin a JDK for the project: `org.gradle.java.home=/path/to/jdk17` in `gradle.properties` (machine-specific, so prefer `~/.gradle/gradle.properties`).

## 2. Wrapper

```bash
gradle wrapper --gradle-version 9.6.0     # needs a Gradle install once
./gradlew wrapper --gradle-version 9.6.0  # upgrade; run it twice to refresh scripts + jar
./gradlew --version
```

Commit `gradlew`, `gradlew.bat`, `gradle/wrapper/gradle-wrapper.jar` and `gradle-wrapper.properties`. In the properties file: `distributionUrl` (full `X.Y.Z`, https), optional `distributionSha256Sum` (checked only when the distribution is not yet downloaded; a mismatch fails the build), `validateDistributionUrl`. Verify the wrapper jar against the published checksum; if a checksum mismatches, check whether the jar was generated by another Gradle version before assuming tampering.

## 3. Android SDK

- `local.properties` with `sdk.dir=C\:\\Users\\you\\AppData\\Local\\Android\\Sdk` (Windows escaping) or the `ANDROID_HOME` environment variable. Do not commit `local.properties`.
- Install the platform and build tools named in the error with the SDK Manager or `sdkmanager`. Accept licenses: `sdkmanager --licenses`.

## 4. Project files

- `settings.gradle(.kts)`: `pluginManagement { repositories { google(); mavenCentral(); gradlePluginPortal() } }` and `dependencyResolutionManagement { repositories { google(); mavenCentral() } }`, then `include(":app")`.
- Root `build.gradle(.kts)`: plugins with versions and `apply false`.
- `gradle/libs.versions.toml`: version catalog (see [dependencies.md](dependencies.md)).
- Module `app/build.gradle(.kts)`: `android { namespace, compileSdk, defaultConfig { minSdk, targetSdk } }`, `dependencies { ... }`.

## 5. gradle.properties

```properties
org.gradle.jvmargs=-Xmx2048m -Dfile.encoding=UTF-8
org.gradle.parallel=true
org.gradle.caching=true
org.gradle.configuration-cache=true   # enable when the plugins in use support it; IDE sync does not use it
android.useAndroidX=true
```

`org.gradle.jvmargs` default heap is small; raise it for big apps (`-Xmx4g`), lower it on low-RAM machines. Keep `android.enableJetifier` off unless a dependency still needs the old support libraries.

## 6. Proxy / corporate network

Put in `~/.gradle/gradle.properties` (not the project): `systemProp.https.proxyHost`, `systemProp.https.proxyPort`, `systemProp.http.*` the same, plus user and password if needed. Android Studio's own proxy setting overrides these inside the IDE. For TLS interception import the CA into the JDK's `cacerts`.

## 7. Windows speed

Antivirus real-time scanning slows builds a lot. Exclude `%USERPROFILE%\.gradle`, the project folder and the SDK from scanning (do not disable the antivirus). Keep the project out of a synced OneDrive folder if you see random file-lock errors. If Group Policy restricts exclusions, move the Gradle cache with `GRADLE_USER_HOME`.

## 8. Verify

```bash
python skills/gradle-android/scripts/gradle_doctor.py check
./gradlew help            # configuration works
./gradlew assembleDebug   # a real build
./gradlew testDebugUnitTest
```
