# More procedures: Working with Remotes

### Pushing to Your Remotes

**Goal:** The command for this is simple: `git push <remote> <branch>`.

**Steps:**

1. If you want to push your `master` branch to your `origin` server (again, cloning generally sets up both of those names for you automatically), then you can run this to push any commits you’ve done back up to the server:
   ```bash
   git push origin master
   ```
