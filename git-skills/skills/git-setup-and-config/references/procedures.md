# More procedures: Setup and Config

### git config core.editor commands

**Goal:** git config core.editor commands

**Steps:**

1. Atom
   ```text
   git config --global core.editor "atom --wait"
   git config --global core.editor "bbedit -w"
   ```
2. Emacs
   ```text
   git config --global core.editor emacs
   ```
3. Gedit (Linux)
   ```text
   git config --global core.editor "gedit --wait --new-window"
   ```
4. Gvim (Windows 64-bit)
   ```text
   git config --global core.editor "'C:\Program
   ```
5. Helix
   ```text
   git config --global core.editor "hx"
   ```
6. Kate (Linux)
   ```text
   git config --global core.editor "kate --block"
   ```
7. nano
   ```text
   git config --global core.editor "nano -w"
   ```
8. Notepad (Windows 64-bit)
   ```text
   git config core.editor notepad
   ```
9. Notepad++ (Windows 64-bit)
   ```text
   git config --global core.editor "'C:\Program
   Files\Notepad++\notepad++.exe' -multiInst -notabbar -nosession
   ```
10. Scratch (Linux)
   ```text
   git config --global core.editor "scratch-text-editor"
   ```
11. Sublime Text (macOS)
   ```text
   git config --global core.editor "/Applications/Sublime\
   Text.app/Contents/SharedSupport/bin/subl --new-window --wait"
   ```
12. Sublime Text (Windows 64-bit)
   ```text
   git config --global core.editor "'C:\Program Files\Sublime
   ```
