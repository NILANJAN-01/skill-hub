# 06. Pull requests

1. One skill per pull request.
2. Titles: `Add <name> skill` or `Update <name> skill: <what changed>`.
3. Tooling changes go in their own PR.
4. Do not commit source documents (PDFs, books) or secrets.
5. Respect licenses: derived content needs a `license` field and a `THIRD_PARTY_NOTICES.md` entry.
