How the hub works

Every skill is a folder in skills/ with a SKILL.md. Skills are grouped into plugins in .claude-plugin/marketplace.json, so Claude Code can install a whole category at once. tools/build_catalog.py generates catalog.json, which powers this site and the find-skills skill. tools/validate_skills.py checks every skill against the Agent Skills spec in CI.

Install

/plugin marketplace add NILANJAN-01/skill-hub
/plugin install git-branching --marketplace NILANJAN-01/skill-hub   # one category
/plugin install git-skills --marketplace NILANJAN-01/skill-hub      # every Git skill

# or copy one skill
git clone --depth 1 https://github.com/NILANJAN-01/skill-hub.git
cp -r skill-hub/skills/git-rebasing ~/.claude/skills/

Contribute

cp -r template skills/my-skill          # write SKILL.md
# add "./skills/my-skill" to a plugin in .claude-plugin/marketplace.json
python tools/build_catalog.py
python tools/validate_skills.py

Generate skills from a PDF (skillforge)

The Git skills were generated by the skillforge skill, an offline generator that uses open-source NLP and needs no API keys or LLM:

1 · ParsePyMuPDF reads fonts and layout to separate headings, prose, code blocks, inline code, captions and note/warning callouts.
2 · IndexEach subsection is indexed with scikit-learn TF-IDF and light stemming, so "rebase", "rebasing" and "rebased" match.
3 · PlanTopics are matched to the best sections across the whole book; the plan is editable JSON.
4 · AuthorProcedures come from instruction → command → output sequences; concepts from TextRank, keyphrases from YAKE, safety rules from callouts.
pip install -r skills/skillforge/scripts/requirements.txt
python skills/skillforge/scripts/skillforge.py your-book.pdf --plan-only
python skills/skillforge/scripts/skillforge.py your-book.pdf --topics "rebase, hooks, merge conflicts"

Every statement in a skill is quoted from the source, so skills stay faithful to the book, though some extracted bullets can be noisy. Review a skill before you rely on it.
