# skill-hub

[![Validate skills](https://github.com/NILANJAN-01/skill-hub/actions/workflows/validate.yml/badge.svg)](https://github.com/NILANJAN-01/skill-hub/actions/workflows/validate.yml)

**A centralized hub of Agent Skills that work in every major AI coding agent:** Claude Code, Google Antigravity, Devin, GitHub Copilot, Cursor, Windsurf, OpenAI Codex and Gemini CLI.

**New here? Follow the [step-by-step guide](GUIDE.md)**: install a skill into your agent in about 5 minutes.

Browse every skill in **[skills/README.md](skills/README.md)**. **[examples/PROMPTS.md](examples/PROMPTS.md)** shows what to say to your agent for each one.

A skill is a folder with a `SKILL.md` file in the open [Agent Skills](https://agentskills.io/specification) format. The YAML frontmatter (`name`, `description`) tells the agent *when* to use the skill. The Markdown body tells it *how*. Agents read only the descriptions up front and load the full skill when a task matches. Because the format is shared, each skill here is written **once** and installed into whichever agent you use.

## Install

### Option 1: the hub installer: one command sets up everything

`tools/install.py` needs only Python 3.8+, with no clone and no Node. **`--setup` does everything in one go:** it detects which AI agents and IDEs are installed, installs every skill for them, and registers the **skill-hub MCP server** in each agent's MCP config, so agents can also search the whole hub and load any skill on demand. It shows the exact plan and changes nothing until you say yes.

```bash
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/NILANJAN-01/skill-hub/main/tools/install.py | python3 - --setup

:: Windows Command Prompt (cmd)
curl -fsSL https://raw.githubusercontent.com/NILANJAN-01/skill-hub/main/tools/install.py | python - --setup

# Windows PowerShell
irm https://raw.githubusercontent.com/NILANJAN-01/skill-hub/main/tools/install.py -OutFile install.py
python install.py --setup

# afterwards
python install.py --doctor       # what is set up per agent, and a self-check of the MCP server
python install.py --uninstall    # remove everything it set up
```

Run it with **no options** for a menu instead: set up everything, choose agents and skills, check (doctor), or remove. The [guide](GUIDE.md) walks through it step by step.

How the MCP server is set up: the installer copies the hub to `~/.skill-hub/hub` (or `$SKILLHUB_HOME/hub`) and adds one `skill-hub` entry to each agent's MCP config ([locations below](#where-each-agent-reads-skills)). It merges into existing files, changes only its own entry, keeps a `.skillhub-backup` of each file it first edits, and leaves files it can't parse safely (for example JSON with comments) alone and prints the entry to paste instead. The server is read-only; add `--mcp-allow-install` to let agents install skills after you approve each plan.

**Other MCP servers, into every agent at once.** The same installer adds any stdio MCP server to every detected agent's config (user-level, merged, with backups). It has presets for common servers, and `--mcp-test` starts the server and checks that it answers before anything is written:

```bash
python install.py --list-mcp                                        # servers each agent has, and the presets
python install.py --add-mcp playwright --mcp-test                   # preset: filesystem, memory, fetch, git, time, playwright, github, ...
python install.py --add-mcp filesystem --mcp-arg ~/work             # presets that need arguments
python install.py --add-mcp github --mcp-env GITHUB_PERSONAL_ACCESS_TOKEN   # secret copied from your environment
python install.py --add-mcp mydb --mcp-command "uvx my-db-mcp --readonly"   # any other server
python install.py --remove-mcp playwright
```

On Windows, `npx`-style launchers are written as `cmd /c npx ...` so agents can start them.

More ways to run it:

```bash
# guided questions, nothing else to download
curl -fsSL https://raw.githubusercontent.com/NILANJAN-01/skill-hub/main/tools/install.py | python3 -

# Windows PowerShell
# (to read the script before running it, open the URL in a browser or `curl -O` it first)
irm https://raw.githubusercontent.com/NILANJAN-01/skill-hub/main/tools/install.py -OutFile install.py
python install.py

# from a clone
python tools/install.py

:: Windows, one shot from a clone: checks Python 3.8+, shows detected agents, asks y/n, runs --setup
install.bat
install.bat --check      :: only check the preconditions
```

Those commands read the latest `main`. For a fixed, reproducible version, use the installer attached to a [release](https://github.com/NILANJAN-01/skill-hub/releases); it installs that same release:

```bash
curl -fsSL https://github.com/NILANJAN-01/skill-hub/releases/latest/download/install.py | python3 -
```

Each release also lists `SHA256SUMS`, one zip per skill (for upload UIs such as Claude.ai) and `catalog.json`. When the installer downloads a release (`--ref v1.3.0` or `SKILLHUB_REF`), it checks the archive against that release's `SHA256SUMS` and stops on a mismatch. Running a fork? Use `--repo owner/name` (or set `SKILLHUB_REPO`) and `--ref <branch-or-tag>`.

The installer:
- **Reads the machine fresh on every run.** It looks for installed apps, commands on your PATH and the agents' config folders.
- **Writes to the fewest folders** that cover every agent you pick. For example, Copilot also reads Claude Code's and Codex's folders, so nothing gets installed twice.
- **Skips skills an agent can already see.** It asks before replacing a skill that differs from the hub, and offers to remove redundant identical copies. A repeat run reports *"Nothing to do"*.

To skip the questions (scripts, CI, dotfiles), pass options instead:

```bash
python install.py --detect                                        # which agents are installed
python install.py --list                                          # agents, plugins, skills
python install.py --setup --yes                                   # everything + MCP server, no questions
python install.py --setup --agent cursor --project .              # everything, one agent, this project
python install.py --agent detected --mcp --global                 # only the MCP server
python install.py --agent claude-code --plugin ai-agent-tools --mcp --global
python install.py --agent detected --all --global --yes           # every skill, no MCP server
python install.py --agent cursor --skill git-rebasing             # one skill, this project
python install.py --agent copilot,claude-code --plugin hub-tools --global
python install.py --agent codex --plugin git-skills --global --dry-run
python install.py --zip dist --plugin git-branching               # one .zip per skill, for upload UIs
```

`--installed` lists the hub skills already installed and the hub version each came from (the installer records this in a small `.skill-hub.json` in each skills folder). `--update` (same as `--force`) refreshes installed skills that differ from the hub in any file, `--remove` uninstalls the selected skills (it asks first), `--tidy` removes redundant copies, and `--each` copies into every agent's own folder instead of shared ones.


## Add a skill to the hub

1. Pick the area and group the skill belongs to (see [the layout](skills/README.md#folder-layout); a new group is just a new folder), then `cp -r template skills/<area>/<group>/<your-skill>` and fill in `SKILL.md`. Give it a specific `description` that says what the skill does and when to use it. Keep the body **agent-neutral**: no instructions that only one IDE understands.
2. Add `"./skills/<area>/<group>/<your-skill>"` to a plugin in `.claude-plugin/marketplace.json`, and add at least 2 example prompts for it to `examples/prompts.json`.
3. Run the tools:
   ```bash
   python tools/build_catalog.py      # regenerate generated files
   python tools/validate_skills.py    # spec + hub + portability checks
   ```
4. Open one pull request per skill, titled `Add <skill> skill` or `Update <skill> skill: <what changed>`. CI runs the same checks.

[CONTRIBUTING.md](CONTRIBUTING.md) has the full rules. Any agent working in this repo follows [AGENTS.md](AGENTS.md), and the [`contribute-skill`](skills/generic/hub/contribute-skill/SKILL.md) skill walks an agent through the whole process.

### Generate skills from a PDF

[`skillforge`](skills/generic/hub/skillforge/SKILL.md) bundles `skillforge.py`, an offline generator that uses open-source NLP and needs no API key or LLM. It turns a technical PDF into focused playbooks, and it produced the Git skills here:

```bash
pip install -r skills/generic/hub/skillforge/scripts/requirements.txt
python skills/generic/hub/skillforge/scripts/skillforge.py book.pdf --plan-only     # review the plan
python skills/generic/hub/skillforge/scripts/skillforge.py book.pdf --topics "rebase, hooks, bisect"
```
