How to use the skill-hub MCP server

Let your AI agent find and read the right skill by itself, so you don't have to type a magic prompt.

What it isQuick startConnect an agent Using itToolsTroubleshooting

What it is

skill-hub has more than 70 skills. Agents only see a one-line description of each, and often trim the list, so a skill is applied only when your request happens to match. The MCP server fixes this: it gives the agent tools to search the catalog and read any skill's full playbook on demand.

You: "undo my last commit" → agent calls recommend_skills → reads git-undoing-things with get_skill → follows its steps.
  • Read-only. It never writes files or runs commands. Install commands are only shown to you.
  • No dependencies. Python 3.8+ standard library only.
  • Local or online. Reads your clone of skill-hub, or GitHub with --remote.

Quick start

1
Get the repository (skip if you already have a clone). 
git clone https://github.com/NILANJAN-01/skill-hub.git
cd skill-hub/mcp-server
2
Check that it starts. You should see the number of skills loaded. 
python -m skillhub_mcp --check
# skillhub_mcp 0.1.0: 76 skills from local clone at ...
3
Add it to your agent (next section), restart the agent, then just ask for what you want.

Connect an agent

Replace /path/to/skill-hub with the real absolute path. On Windows use forward slashes, e.g. C:/Users/you/skill-hub.

{
  "mcpServers": {
    "skill-hub": {
      "command": "python",
      "args": ["-m", "skillhub_mcp"],
      "env": { "PYTHONPATH": "/path/to/skill-hub/mcp-server" }
    }
  }
}

Put this in your agent's MCP configuration file (see your agent's documentation for where it lives). If it supports a working directory option you can use "cwd": "/path/to/skill-hub/mcp-server" instead of env.

claude mcp add skill-hub --env PYTHONPATH=/path/to/skill-hub/mcp-server -- python -m skillhub_mcp

Then run claude mcp list: skill-hub should show as connected.

{
  "mcpServers": {
    "skill-hub": {
      "command": "python",
      "args": ["-m", "skillhub_mcp", "--remote"],
      "env": { "PYTHONPATH": "/path/to/skill-hub/mcp-server" }
    }
  }
}

--remote reads the catalog from GitHub (cached for 15 minutes) so the data is always the latest on main. You still need the mcp-server folder for the code. Use --ref BRANCH to read another branch.

Using it

Talk normally. The agent decides when to call the tools. You can also name the server to be sure.

I committed to the wrong branch. How do I fix it?
Found a matching skill and following its steps…tools: recommend_skills → get_skill (git-undoing-things)
Which skills do you have for testing?
Lists the skills in the testing category.tools: list_categories → search_skills (category = testing-tools)
How do I install git-rebasing for Cursor?
Shows the install commands for you to run.tools: get_install_instructions (does not run anything)

Built-in prompts

Some agents show these in a prompt menu: find_skill (give it a task) and use_skill (give it a skill name).

Skills as resources

Every skill is also available as a resource, skillhub://skill/<name>, for agents that let you attach resources to a chat.

The 8 tools

ToolWhat it does
search_skillsRanked keyword search. Options: category, limit (1–25).
recommend_skillsBest 1–5 skills for a task, with example prompts and install command.
get_skillA skill's full instructions and file list.
read_skill_fileA text file inside a skill (references/…, scripts/…), up to 200 KB.
list_categoriesAll categories with skill counts.
list_pluginsInstallable skill bundles, optionally for one category.
list_agentsSupported AI agents and their skill folders.
get_install_instructionsInstaller, npx skills and native-plugin commands for a skill or plugin.
Safe by design: file reads are limited to skill folders and reject .. and absolute paths. Nothing is ever installed or executed by the server.

Troubleshooting

ProblemFix
No module named skillhub_mcpThe agent can't find the code. Set PYTHONPATH (or cwd) to the mcp-server folder, with an absolute path.
no catalog.json in …--root must point at the repository root. Or use --remote.
Agent shows the server as failedRun python -m skillhub_mcp --check in a terminal with the same settings and read the message. Logs go to stderr only.
python not foundUse the full path to Python in command, or python3 / py.
Agent never uses the toolsRestart the agent after editing the config, and name the server once: "use skill-hub to find a skill for …".
Remote mode errorsNeeds internet access to raw.githubusercontent.com and api.github.com. Otherwise use a local clone.

Try it by hand

You can talk to the server without an agent. It reads one JSON message per line from stdin:

echo '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"search_skills","arguments":{"query":"rebase"}}}' | python -m skillhub_mcp
Source and tests: mcp-server/ in the skill-hub repository. Run the tests with python -m unittest discover -s mcp-server/tests -v. More detail: mcp-server/README.md.
